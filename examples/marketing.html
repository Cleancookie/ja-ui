Questions people actually ask

Do I have to learn any class names?

Twenty-one, and they are all optional. Ten colours, three treatments, two sizes and a handful of nouns the platform has no element for — a badge, a callout, a toast. Everything else is an element selector.

Does it work with React or Vue?

It is plain CSS over plain elements, so yes. Import the stylesheet once. The interactive parts are <dialog>, <details> and [popover], which are the platform's, not a framework's.

What about older browsers?

Modern evergreen browsers only. It leans on color-mix(), :has(), logical properties and cascade layers, and it is not sorry about it.

Can I override it without !important?

That is the whole point of the layers. Everything ja-ui ships lives in @layer, and unlayered CSS beats layered CSS whatever its specificity — so your own stylesheet wins by existing. This page is written that way.
