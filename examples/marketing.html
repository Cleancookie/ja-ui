Why bother

Everything you'd have built anyway

Prototype at the speed of HTML, then ship the prototype. Accessibility, keyboard handling and dark mode come along for free.

Nothing to configure

One stylesheet, one optional script. No build step, no plugin ecosystem, no config file that grows a personality of its own.

Retheme in one file

Every colour, radius, shadow and control height is a custom property. Override the handful you care about and the rest follows.

Accessible without trying

44px touch targets, focus rings you can actually see, focus traps in dialogs, reduced-motion handling. You just write the markup.

Three steps

From npm install to shipped

01

02

03
